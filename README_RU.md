# Общий VPN для домашней сети (Raspberry Pi)

## Что это

Проект позволяет нескольким устройствам дома выходить в интернет через VPN Happ, который работает на Raspberry Pi 5. Сейчас **ничего нового не настроено**: проект на стадии исследования. Трафик телефона уже идёт через VPN на компьютере `dell` (старая настройка), и она не изменена.

## Устройства и адреса

| Устройство | Имя | IP-адрес | Примечание |
|---|---|---|---|
| Raspberry Pi 5 | `pi5home` | `192.168.0.118` | Будущий общий VPN-шлюз, подключён по Wi-Fi (`wlan0`) |
| Компьютер | `dell` | `192.168.0.105` | Сейчас тоже использует Happ (версия 2.17.1) |
| Телефон | Android | `192.168.0.185` | Клиент, статический IP |
| Роутер | — | `192.168.0.1` | Шлюз по умолчанию для всей сети |

Адреса VPN-туннеля (появляются, когда Happ включён):
- на Pi: `happ-xray`, `172.19.0.1/30`
- на `dell`: `tun0`, `172.18.0.1/30`

## Что нужно сделать вам

Ничего из этого не меняет настройки само по себе.

1. **Настройки Wi-Fi на Android.** Пришлите: IP-адрес, шлюз, маску или префикс, DNS-серверы, и задан ли адрес вручную или получен автоматически (DHCP). Ожидаемые значения: IP `192.168.0.185`, маска `/24`, шлюз — либо `192.168.0.105` (компьютер `dell`), либо `192.168.0.1` (роутер).
2. **Happ на компьютере `dell`.** Нужен ли он вам? Если нет, его удалить или оставить? Пока вы не ответите, на `dell` ничего не меняется.
3. **Выбор «включено / выключено» для Pi** (после одобрения проекта). Вы будете задавать его отдельной командой, рядом с переключателем в Happ. Инструкция появится здесь.

## Установка на новое устройство (Raspberry Pi)

Одна команда. Она спросит пароль sudo один раз:

```bash
git clone https://github.com/bayunderground/setup-vpn-gateway.git ~/setup-vpn-gateway && bash ~/setup-vpn-gateway/scripts/new-host-setup.sh
```

Скрипт ставит пакеты, отключает nftables, проверяет Happ, обновляет проект, ставит правило sudo для проверок без пароля и настраивает проверку при каждом запуске системы. Отчёт пишется в `/var/log/vpn-gateway/boot-baseline.log`. Скрипт ничего не меняет в маршрутизации и файрволе. Удалить то, что он добавил: `bash ~/setup-vpn-gateway/scripts/new-host-setup.sh --uninstall`.

Happ устанавливается отдельно, своим установщиком. Скрипт скажет, если Happ не найден.

## Правила безопасности

- Не запускайте `happ-diag --repair`: команда перезапускает Happ.
- Не включайте `nftables.service` на Pi: его настройки стирают все правила файрвола.
- Не удаляйте сетевые правила без проверки и одобрения.
- Если состояние VPN неясно, считайте, что он **выключен и заблокирован**.
