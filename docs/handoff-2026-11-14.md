Use this file to start a new chat. Everything below was observed on 2026-11-14 unless marked otherwise.
Evidence labels: VERIFIED = directly observed. INFERRED = reasoned from observations. USER = reported by the user. UNKNOWN = not yet checked.

## 1. Goal

Shared IPv4-only Happ VPN gateway on a Raspberry Pi 5 (`pi5home`). Clients: Android and Dell. Full rules are in `CLAUDE.md`; phased plan in `DEVELOMPENT_PLAN.md`.

Safety rules that matter most:
- Happ's `happd.service` being active is NOT the enabled/disabled signal.
- Unknown state fails closed.
- Never flush the global nftables ruleset. Never enable the stock `nftables.service` (its config starts with `flush ruleset`).
- No client cutover before routing, NAT, DNS and kill-switch are tested.
- Dell cleanup (rule 8000 and others) only after owner confirmation and user approval.
